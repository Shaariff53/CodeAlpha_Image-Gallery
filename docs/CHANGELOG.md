# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2024-05-24

### Added

- Initial release of SnapGallery
- Image gallery with category filtering (nature, city, animals, people)
- Responsive grid layout with smooth animations
- Lightbox viewer with full-screen image viewing
- Keyboard navigation support (arrow keys, ESC)
- Category-based image filtering
- Image overlay information (title, category, description)
- Mobile-responsive design
- Dark mode support ready
- Accessibility features (ARIA labels, semantic HTML)
- TypeScript for type safety
- Tailwind CSS for styling
- shadcn/ui components
- React Router for routing
- React Query for state management
- Vitest for testing
- ESLint for code quality
- Comprehensive documentation

### Components

- Image grid with lazy loading
- Interactive lightbox modal
- Category filter buttons
- Navigation controls
- Footer with keyboard hints

### Documentation

- README with features and quick start
- Architecture guide
- Setup and development guide
- Contributing guidelines
- Code of conduct
- MIT License

### Technical

- Built with React 18 and TypeScript 5
- Vite 5 for fast development and builds
- Tailwind CSS 3 for styling
- Radix UI primitives
- Responsive design (mobile-first)
