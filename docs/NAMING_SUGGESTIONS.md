## Renaming Instructions (If needed)

To rename the repository from `Image-Gallery` to `SnapGallery`:

1. **On GitHub**:
   ```
   Settings → General → Repository name
   Change: Image-Gallery → snapgallery
   ```

2. **Update Local Remote**:
   ```bash
   git remote set-url origin https://github.com/Shaariff53/snapgallery.git
   ```

3. **Update Documentation**:
   - Update README.md links
   - Update package.json (already done ✅)
   - Update any hardcoded references
